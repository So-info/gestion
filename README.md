# So Info — version professionnelle simple

Site HTML statique pour la gestion locale des clients, fiches de prise en charge, devis et factures.

## Mise en ligne
1. Décompressez l'archive.
2. Envoyez `index.html` et le dossier `assets` dans le dépôt GitHub Pages existant.
3. Attendez la publication GitHub Pages.

## Fonctionnalités
- Interface responsive pour téléphone et ordinateur.
- Gestion de clients enregistrée dans le navigateur.
- Fiche de prise en charge, avec deux zones de signature au doigt/stylet (client et So Info), intégrées au document imprimé/PDF.
- Création de devis et factures avec calcul du total TTC.
- Impression/enregistrement en PDF et préparation d'e-mail via l'application de messagerie.
- Export/import de sauvegarde JSON.

## Important
Cette version n'utilise pas de serveur : les données sont enregistrées localement dans le navigateur et ne se synchronisent pas entre appareils. L'e-mail est préparé dans l'application de messagerie, il n'est pas envoyé automatiquement. Vérifiez les mentions légales et les conditions avant un usage professionnel.
